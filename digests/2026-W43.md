# 2026-W43 周报（2026-10-19 ~ 10-25）

> 基于公开报道与官方公告整理（检索日期 2026-10-24），以官方最新公告为准。

## 本周行动项

1. **PHP（P0）**：PHP2Shell 两个未认证 RCE 已有**披露前在野利用**，所有受支持 8.x 分支已于 10-21 发补丁 —— 立即升级；修补困难的站点参考 CERT-EU 建议评估短暂下线更新。
2. **Node.js**：10-21 官方安全发布覆盖 26.x / 24.x / 22.x（含 Brotli 解码器越界写 → RCE），升级到各分支最新补丁版。
3. **Go**：Go 1.26.0 stdlib 一次性受 29 个已知漏洞影响，升级到 ≥ 1.26.4 并重新编译发布；另留意 10-21 新公布的 crypto/x509 CVE-2026-111943。
4. **Java/Spring**：核对 8-20 的 91 个 Spring 公告批次是否已消化；关注新公告 CVE-2026-47836（HIGH）。
5. **Python**：`mcp` 包升级 ≥ 1.28.1（CVE-2026-59950）；核查历史上是否引入过 LiteLLM 1.82.7 / 1.82.8 恶意版本，有过则按入侵事件处理。

## 重点事件

### PHP · PHP2Shell —— 核心未认证 RCE（P0）

- CVE-2026-109618 / CVE-2026-109619，PHP 核心一对 RCE：内存耗尽（OOM）处理可把 PHP 打断在内部请求数据只初始化一半的状态，进而劫持执行流。
- 2026-10-21 所有受支持 8.x 分支同步发补丁；Wiz 估算影响面约占互联网站点 70%；CERT-EU 发布 2026-018，路透社报道有政府网站为抢修临时下线。
- AWS MadPot 蜜罐观察到**公开披露前**的利用。
- 详细笔记：[languages/php/2026-10-php2shell.md](../languages/php/2026-10-php2shell.md)

### Node.js · 10-21 官方安全发布

- 影响 26.x / 24.x / 22.x；含 Brotli 解码器越界写，可导致远程代码执行；HKCERT 整体定级 Medium，但对服务端不可信输入场景应按高危对待。
- 详细笔记：[languages/nodejs/2026-10-security-releases.md](../languages/nodejs/2026-10-security-releases.md)

### Go · stdlib 批量修复 + crypto/x509 新 CVE

- 10-21 公布 CVE-2026-111943（crypto/x509：部分平台路径下系统根证书处理缺陷）。
- Go 1.26.0 stdlib 受 29 个漏洞影响，社区建议 ≥ 1.26.4。
- 年内相关：CVE-2026-33810（crypto/x509 `excludedSubtrees` 大小写敏感 → 认证绕过）、CVE-2026-32283（crypto/tls key update DoS）、CVE-2026-84304（gRPC-Go HTTP/2 DoS，9 月）。
- 详细笔记：[languages/go/2026-10-stdlib.md](../languages/go/2026-10-stdlib.md)

### Java · Spring 8 月公告潮的余波

- 8-20 Spring 单日发布 91 个安全公告，企业应用消化成本高；10 月仍有新公告（如 HIGH 级 CVE-2026-47836、MEDIUM 级 CVE-2026-47834）。
- 值得回看：CVE-2026-40976（Spring Boot 4.0.0–4.0.5，严重级）、CVE-2026-22737（Spring Framework 脚本模板视图信息泄露）、CVE-2026-41003（Spring Security RelyingPartyRegistration）。
- 生态动态：Atlassian 10-20 公告含 162 个 high + 14 个 critical 第三方组件漏洞。
- 详细笔记：[languages/java/2026-spring-2026-advisories.md](../languages/java/2026-spring-2026-advisories.md)

### Python · MCP SDK 漏洞 + LiteLLM 供应链投毒（回顾）

- CVE-2026-59950：`mcp`（Model Context Protocol Python SDK），修复于 1.28.1。
- 3-24 LiteLLM 1.82.7 / 1.82.8 恶意版本投毒（与 TeamPCP 活动相关，同期波及 Telnyx）；攻击者还先污染了一个安全扫描器让后门通过检查 —— 安全工具本身成了攻击面。
- 详细笔记：[languages/python/2026-supply-chain-and-mcp.md](../languages/python/2026-supply-chain-and-mcp.md)
